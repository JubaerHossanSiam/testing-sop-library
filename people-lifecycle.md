# People Lifecycle

## Purpose

Provide the canonical map of the Blinto team-member lifecycle and show which document owns each stage.

This page is a navigation/reference document. It does not duplicate the detailed procedures owned by the linked SOPs.

## Lifecycle

**Workforce need → Hiring → Offer/engagement → Onboarding → Active employment & development → Performance review → Role/employment change → Offboarding**

## Canonical Ownership

| Stage | Canonical document | Purpose |
| --- | --- | --- |
| Identify and fill a role | [Hiring](./hiring.md) | Request, source, assess, select, and prepare an offer recommendation |
| Prepare a new joiner | [Employee Onboarding](./employee-onboarding.md) | Prepare access, orientation, role setup, and initial integration |
| Evaluate and develop | [Performance Review](./performance-review.md) | Run the applicable recurring/formal performance review process |
| End employment/engagement | [Employee Offboarding](./employee-offboarding.md) | Coordinate handover, access removal, assets, records, and exit closeout |
| Run an internship | [Internship Program](./internship-program.md) | Internship-specific learning, mentoring, evaluation, and outcomes while reusing the shared lifecycle processes |

## Canonical Rule

Special programs and departments should reuse these lifecycle processes unless their actual workflow materially differs.

For example, the Internship Program should not contain its own duplicate instructions for account setup or access removal. It should call the onboarding/offboarding process and document only internship-specific requirements.

## Known Follow-Up Resources

As the library matures, independently reusable resources may be added where justified, such as:

- job description template;
- interview scorecard;
- offer/appointment templates;
- onboarding checklist;
- access provisioning/deprovisioning checklist;
- performance review forms;
- exit checklist.

These should be created only when their current operational requirements are confirmed and they have independent reuse value.
