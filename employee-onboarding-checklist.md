# Employee Onboarding Checklist

## Purpose

Provide the reusable execution checklist for [Employee Onboarding](./employee-onboarding.md). The SOP owns the process; this checklist verifies that the required setup is completed for each new joiner.

## Before Start Date

### Employment & Ownership

- [ ] Accepted offer/appointment/engagement documentation is on record.
- [ ] Start date is confirmed.
- [ ] Role/title and reporting line are confirmed.
- [ ] Team/Department Lead is confirmed.
- [ ] Onboarding coordinator/owner is confirmed.
- [ ] Mentor/buddy is assigned where applicable.

### Workspace & Equipment

- [ ] Required workspace is ready where applicable.
- [ ] Required company equipment is prepared and recorded.
- [ ] Any equipment/accountability acknowledgement required by current policy is prepared.

### Identity & Access

Provision only what the role requires.

- [ ] Company email/identity is prepared.
- [ ] ClickUp access is prepared where required.
- [ ] Google Workspace/Drive access is prepared where required.
- [ ] Approved communication tools are prepared.
- [ ] Approved password-manager access is prepared where required.
- [ ] Department/project tools are identified.
- [ ] Client/privileged access is withheld until actually required and appropriately authorized.
- [ ] MFA/2FA requirements are communicated/configured where applicable.

### Pre-Start Communication

- [ ] Start date/time is communicated.
- [ ] Office/location or remote joining instructions are communicated.
- [ ] Point of contact is provided.
- [ ] Any required pre-start documents/actions are communicated.

## Day One / Initial Orientation

### People Operations Orientation

- [ ] Company introduction/context completed.
- [ ] Relevant culture/values introduced.
- [ ] Employment/engagement basics explained.
- [ ] Working/attendance expectations introduced.
- [ ] Key workplace policies/resources provided or linked.
- [ ] Security and confidentiality expectations introduced.
- [ ] Communication and escalation channels explained.
- [ ] SOP Library introduced as the canonical operational knowledge source.

### Team & Role Orientation

- [ ] Team and key collaborators introduced.
- [ ] Role purpose and expected outcomes explained.
- [ ] Reporting and communication expectations confirmed.
- [ ] Relevant projects/clients introduced where appropriate.
- [ ] Required SOPs/guides/resources identified.
- [ ] Initial work or learning plan assigned.
- [ ] Mentor/buddy introduction completed where applicable.

## First Week

- [ ] Required systems can be accessed successfully.
- [ ] Required equipment is working.
- [ ] Initial tasks/learning activities are underway.
- [ ] New joiner knows where to find tasks, documentation, and support.
- [ ] New joiner understands immediate priorities.
- [ ] Probation/internship/check-in expectations are explained where applicable.
- [ ] Any outstanding onboarding issue has an owner and target date.

## Closeout

- [ ] Administrative setup is complete.
- [ ] Required access/equipment is complete.
- [ ] Role/manager/priorities are understood.
- [ ] Initial work/learning plan is clear.
- [ ] Required policy/security orientation is complete.
- [ ] Onboarding is marked complete in the applicable tracking system.
