# SEO Client Intake Checklist

## Purpose

Collect the minimum information required to use [SEO Client Intake & Routing](./seo-client-intake-and-routing.md) and select the appropriate starting path.

## Client & Website Context

- [ ] Client/company name recorded.
- [ ] Primary contact recorded.
- [ ] Business/products/services understood at a basic level.
- [ ] Current website status confirmed.
- [ ] Website URL collected if one exists.
- [ ] Whether a major redesign/rebuild/migration is planned is confirmed.

## Market & Audience

- [ ] Primary target audience understood.
- [ ] Target locations/markets understood.
- [ ] Important products/services/categories identified.
- [ ] Known competitors/examples captured where useful.

## Business Goal

- [ ] Primary desired outcome identified (for example leads, sales, bookings, qualified traffic, local visibility, product discovery).
- [ ] Current problem/challenge described.
- [ ] Any known urgency/timeline recorded.
- [ ] Any material commercial/launch deadline recorded if relevant.

## Existing SEO / Data

Where applicable:

- [ ] Existing SEO work/provider/history noted.
- [ ] Known traffic/ranking/indexing issue noted.
- [ ] Known migration/redesign history noted.
- [ ] Analytics/Search Console availability noted, without requesting access prematurely.
- [ ] Known penalty/security/indexing concern escalated.

## Routing Decision

Choose one initial route:

- [ ] Existing website → Website SEO Audit
- [ ] New/no meaningful website → Website Architecture & SEO Planning
- [ ] Existing website + major rebuild → Audit current site + plan new architecture
- [ ] Specialized case → SEO Lead determines downstream path

## Handoff

- [ ] Recommended starting service/workstream recorded.
- [ ] Required next-step inputs listed.
- [ ] Responsible SEO owner identified.
- [ ] Quotation/scoping direction recorded.
- [ ] Next canonical SOP/workstream identified where available.
